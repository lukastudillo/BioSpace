# BioSpace - Sistema de Gestión y Simulación Hídrica de Plantas (TEL102)

Aplicación de escritorio local desarrollada en **C++** con interfaz gráfica en **Qt** para el monitoreo, inventario persistente y simulación de evaporación/humedad de plantas de interior.

## Estructura del Repositorio y Directorio de Evidencias
* `/src` → Código fuente en C++ (`.h`, `.cpp`) y archivos de interfaz Qt (`.ui`, `.pro` / `CMakeLists.txt`).
* `/docs` → Informes de cada hito, Carta Gantt y bitácoras de planificación.
* `/evidencias` → Documentos de diseño matemático, capturas de interfaz y reportes de auditoría de memoria con Valgrind.
* `/data` → Archivos locales de prueba para persistencia (`.csv`).
